  🚀 Testing Gambiarra - Step by Step

  1. Install Dependencies First

  cd gambiarra
  pip install -r requirements.txt

  2. Start the Test LLM Server (Terminal 1)

  cd gambiarra/test-llm
  python main.py
  You should see:
  🧠 Starting Gambiarra Test LLM Server...
  📍 OpenAI API compatible endpoint: http://localhost:8001

  3. Start the Gambiarra Server (Terminal 2)

  cd gambiarra/server
  python main.py
  You should see:
  🚀 Starting Gambiarra Server...
  📍 WebSocket endpoint: ws://localhost:8000/ws

  4. Run the Integration Test (Terminal 3)

  cd gambiarra
  python test_integration.py

  This will test the complete flow automatically and should show:
  🧪 Starting Gambiarra Integration Test
  1️⃣ Testing Test LLM Server...
  ✅ Test LLM Server: healthy
  2️⃣ Testing Gambiarra Server...
  ✅ Gambiarra Server: healthy

  ✅ WebSocket connection established
  4️⃣ Testing Session Creation...
  ✅ Session created: [session-id]
  5️⃣ Testing User Message with AI Response...
  🎉 ALL TESTS PASSED!

  5. Try the Client Manually (Terminal 4)

  cd gambiarra/client
  python main.py --workspace .

  This starts the interactive client. You should see approval prompts like:
  🔐 APPROVAL REQUEST
  Tool: read_file
  Risk Level: low
  Description: Read file contents
  Parameters: {"path": "README.md"}

  Approve? (y/n/m for modify): y

  🐛 If Something Goes Wrong

  Check Health Endpoints:

  # Test LLM health
  curl http://localhost:8001/health

  # Gambiarra server health  
  curl http://localhost:8000/health

  Common Issues:

  1. "ModuleNotFoundError" → Run pip install -r requirements.txt
  2. "Port already in use" → Kill existing processes:
  pkill -f "python main.py"
  3. "Connection refused" → Make sure servers started successfully
  4. Import errors → Add current directory to Python path:
  export PYTHONPATH="${PYTHONPATH}:$(pwd)"

  Debug Mode:

  If you want more detailed logs, run with:
  python main.py --debug
